# 使用 Muse Image 修改幻灯片

在设置中将图片模型的提供方设为 OpenAI 兼容格式，API 地址设为
`https://openrouter.ai/api/v1`，图片模型设为 `meta/muse-image`，并在设置中
填写自己的 OpenRouter API 密钥。文本模型可独立配置。使用前请确认模型和账户可用；
每次生成或编辑图片可能产生费用。

在预览中选择“编辑页面”，输入修改要求并生成。系统将当前页图片作为第一张参考图，
把修改要求发给图片模型；选中的区域或其他参考图片随后提供。成功结果保存为新的页面
图片版本，可通过版本历史切换回先前版本。图片比例、文字准确性和未修改区域的保真度
取决于模型返回结果，需要人工检查。

普通 PPTX 导出以整页图片为基础；“可编辑 PPTX”是独立导出流程，仍可能使用 OCR
和图像处理来拆分元素。它不会参与上述网页编辑流程。
